	ex02:
Requires making pairs of numbers, or pairs of pairs
The only relevant number is the last number of the pair
 -> no "physical" pair is needed, as long as recursion level is known.

Algorithm:
	Recursively:
		1. Make pairs
		2. Sort pairs by last number
		3. Repeat until only one pair remains

	Example:
		1. 1 2 3 4 5 6 7 8
		2. (1,2) (3,4) (5,6) (7,8)
		3. (2,4) (6,8)
		4. (4,8)
		5. 8

	Exit recursion and:
		1. Move all b's except b1 into a temporary container
		2. Main should only hold b1 and all a's
		3. (Binary) insert from temporary container into main container
			Insert using Jacobsthal numbers to minimize comparisons
			Otherwise, insert back to front (bx, b(x-1), ...)

	-----------------------------------------------------------------------

	r = recursion

	r0 = 1: one number
	r1 = 2: pair of numbers
	r2 = 4: pair of pairs
	r3 = 8: pair of pairs of pairs

	Size of one pair
		(2^r)

	(a) value of pair n
		data[n * (2^r) - 1]

	(b) value of pair n
		data[n * (2^r) - 1 - (2^r / 2)]

	total pairs
		container.size() / (2^r)

	compare two elements:
		std::max(_aValue(r, n), _bValue(r, n));


class variables:
	Container _c
		holds input, is edited along the way
		needs to keep changes between recursions

function variables:
	recursionDepth
		holds depth of recursion
		for potential calculations / knowing when to stop

	pairSize
		number of elements in one pair
		to calculate index of a pair's value

	totalPairs
		number of pairs in input

	pend (temp container)
		temporary container
		to hold to be sorted values
