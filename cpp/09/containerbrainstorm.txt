	ex02:
Requires making pairs of numbers, or pairs of pairs
The only relevant number is the last number of the pair
 -> no "physical" pair is needed, as long as recursion level is known.

	r = recursion

	r0 = 1: one number
	r1 = 2: pair of numbers
	r2 = 4: pair of pairs
	r3 = 8: pair of pairs of pairs

	Size of one pair
		(2^r)

	(a) value of pair n
		data[n * (2^r) - 1]

	(b) value of pair n
		data[n * (2^r) - 1 - (2^r / 2)]

	total pairs
		container.size() / (2^r)

	compare two elements:
		std::max(_aValue(r, n), _bValue(r, n));


class variables:
	Container _c
		holds input, is edited along the way
		needs to keep changes between recursions

function variables:
	recursionDepth
		holds depth of recursion
		for potential calculations / knowing when to stop

	pairSize
		number of elements in one pair
		to calculate index of a pair's value

	totalPairs
		number of pairs in input

	pend (temp container)
		temporary container
		to hold to be sorted values
